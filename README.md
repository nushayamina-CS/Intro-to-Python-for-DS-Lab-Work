**Intro to Python for Data Science** 

**About This Repository** 

This repository contains my practical lab assignments and exercises completed during the **Introduction to Python for Data Science** (AMDS 2008\) course. 

Throughout the course, I practiced Python programming fundamentals, worked with different data structures, and learned how to clean, process, and analyze datasets using Python. 

The repository includes Jupyter notebooks containing my solutions, along with datasets used for hands-on practice. 

**Course Contents** 

**Lab 1: Python Lists** 

**File:** AMDS\_List\_Lab1.ipynb 

In this lab, I practiced working with Python lists and performing different operations on them. 

Topics covered: 

* Creating, accessing, and modifying lists   
* List indexing and slicing   
* Adding, removing, and updating elements   
* Sorting, reversing, and merging lists   
* Finding maximum, minimum, sum, and average values   
* Counting frequencies and removing duplicates   
* Using loops and list comprehensions   
* Working with nested lists and matrices   
* Solving practical problems involving student marks and cricket scores 

**Lab 2: Python Dictionaries and Programming Logic** 

**File:** AMDS\_Dictionary\_Lab2.ipynb 

This lab focused on Python dictionaries, loops, conditional statements, and problem-solving. 

Topics covered: 

* Using for and while loops   
* Applying conditional statements   
* Creating and updating dictionaries   
* Working with dictionary keys and values   
* Counting word and character frequencies   
* Performing mathematical calculations   
* Implementing input validation   
* Building simple interactive programs 

Practical exercises included: 

* Student Profile and Grade Management   
* Store Inventory Management   
* Contact Book   
* Number Guessing Game   
* PIN Verification System   
* Automated Voting System 

**Lab 3: Data Cleaning and Analysis** 

**File:** AMDS\_Data\_Cleaning\_Lab3.ipynb 

In this lab, I worked with student and sales datasets to practice data cleaning, preprocessing, and basic analysis using **Pandas and NumPy**. 

Topics covered: 

* Loading and exploring datasets   
* Identifying missing and duplicate values   
* Detecting invalid data   
* Handling missing values using median imputation   
* Converting and standardizing data types   
* Removing duplicate records   
* Creating calculated columns   
* Assigning student grades and Pass/Fail results   
* Calculating sales values   
* Grouping and summarizing data   
* Exporting cleaned datasets into CSV and Excel formats 

I also performed basic analysis, including calculating average student marks by department and total sales by product and region. 

**Dataset:** Python\_Lab\_Raw\_Datasets\_Lab3.xlsx 

This Excel workbook contains the original student and sales datasets used for the data-cleaning exercises.
